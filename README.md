# Giza — Where Stone Meets Story

A responsive UX/UI concept website for Giza, Egypt, built from the supplied Giza information and the eight supplied images.

## Run locally
Open `index.html` in a browser. No build step or package installation is required.

## Design direction
- Palette: sun-baked limestone, amber dunes, burnt terracotta and dark brown.
- Editorial serif headlines paired with a clean system sans-serif body.
- Large photography, rounded cards, high contrast, responsive layouts.
- Navigation anchors: Landmarks, Heritage, Timeline, Explore.
- All supplied images are included in `assets/` and placed according to the related content.

## Source basis
The written content follows the uploaded Giza document: architecture landmarks, intangible cultural heritage, and historical timeline.
